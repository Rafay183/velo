# Code of Conduct

We want Velo to be a friendly, welcoming project for everyone, from first-time contributors to experts.

**Expected:** be respectful and patient, assume good intent, give constructive feedback, and help newcomers.

**Not acceptable:** harassment, insults, discriminatory language, personal attacks, or publishing others' private information.

Maintainers may remove comments, commits or contributors that break these rules.
Report problems privately to the maintainers via GitHub.

This policy is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
